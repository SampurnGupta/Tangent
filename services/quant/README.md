# tangent-quant

Stateless quantitative computing service for Tangent.
- Time-additive log returns
- Sample covariance & Ledoit-Wolf shrinkage
- SciPy SLSQP Max-Sharpe optimization with asset caps (15%), sector caps (25%), and asset class bounds
- Deterministic yield accrual model for synthetic assets (FDs/Bonds)
- Seeded Monte Carlo efficient frontier and wealth projection simulations
- Marginal impact calculation for Decision Studio
